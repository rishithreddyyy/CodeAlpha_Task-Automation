# CodeAlpha - Task Automation with Python Scripts

A modular, robust Python task automation project built for **CodeAlpha**. This repository provides solutions for automating real-life repetitive tasks using core Python libraries and techniques.

---

## 🎯 Project Overview & Covered Ideas

You can choose any individual automation script or run the interactive suite that covers all three tasks:

| # | Task Idea | Script | Key Concepts Used | Description |
|---|-----------|--------|-------------------|-------------|
| **1** | **Move all `.jpg` files to a new folder** | `task1_move_jpg.py` | `os`, `shutil`, `file handling` | Scans a folder, filters JPEG images (`.jpg`, `.jpeg`, case-insensitive), handles duplicate names, and moves them to an archive folder. |
| **2** | **Extract all email addresses from a `.txt` file** | `task2_extract_emails.py` | `re`, `file handling`, `os` | Parses text using regular expressions to find all valid emails, strips trailing punctuation, removes duplicates, and saves clean, sorted results. |
| **3** | **Scrape the title of a fixed webpage** | `task3_scrape_title.py` | `requests`, `re`, `file handling`, `os` | Sends an HTTP GET request with a browser User-Agent, extracts the `<title>` tag via regex, unescapes HTML entities, and saves metadata to a text file. |

## ⚙️ Installation & Setup

1. **Clone or open the project folder**:
   ```bash
   cd "CodeAlpha_Task Automation"
   ```

2. **(Optional) Create a virtual environment**:
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS/Linux:
   source venv/bin/activate
   ```

3. **Install required dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
   *(Only `requests` is required; `os`, `shutil`, `re`, `html`, and `argparse` are part of the Python Standard Library).*

## 🚀 How to Run

### Option A: Interactive Master Controller
Run `main.py` to get an interactive menu:
```bash
python main.py
```

```text
======================================================================
           CODEALPHA - PYTHON TASK AUTOMATION SUITE
======================================================================
  Select an automation task to run:
  [1] Move all .jpg files to a new folder       (os, shutil)
  [2] Extract email addresses from a .txt file  (re, file handling)
  [3] Scrape title of a fixed webpage           (requests, re)
  [4] Run complete demo for all 3 tasks
  [5] Exit
======================================================================
```

You can also run tasks or the demo directly via CLI argument:
```bash
python main.py --task 1   # Run Task 1
python main.py --task 2   # Run Task 2
python main.py --task 3   # Run Task 3
python main.py --task 4   # Run Complete Demo for all 3
```

---

### Option B: Run Standalone Scripts

Each script can be run independently with custom arguments or interactive prompts:

#### 1. Move `.jpg` Files (`task1_move_jpg.py`)
```bash
# Interactive mode (prompts for paths, auto-creates sample files if needed):
python task1_move_jpg.py

# Command-line arguments mode:
python task1_move_jpg.py --source "my_photos" --dest "jpg_archive" --create-samples
```
* **Features:**
  * Checks for `.jpg` and `.jpeg` (case-insensitive: `.JPG`, `.JPEG`).
  * Non-matching files (e.g. `.png`, `.pdf`, `.txt`) are kept intact in the source directory.
  * Duplicate name collision resolution (renames to `file_1.jpg` instead of overwriting).

---

#### 2. Extract Email Addresses (`task2_extract_emails.py`)
```bash
# Interactive mode:
python task2_extract_emails.py

# Command-line arguments mode:
python task2_extract_emails.py --input "contacts.txt" --output "cleaned_emails.txt" --create-samples
```
* **Features:**
  * Regular expression: `r'\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}\b'`.
  * Deduplicates email addresses and normalizes them to lowercase.
  * Outputs alphabetical sorted list with timestamp and count header.

---

#### 3. Scrape Webpage Title (`task3_scrape_title.py`)
```bash
# Interactive mode (defaults to Wikipedia):
python task3_scrape_title.py

# Command-line arguments mode:
python task3_scrape_title.py --url "https://example.com" --output "title_result.txt"
```
* **Features:**
  * Custom `User-Agent` to prevent `403 Forbidden` errors on strict web servers.
  * Configurable timeout to prevent hanging.
  * Regular expression extraction of `<title>` tag with `re.DOTALL` and `re.IGNORECASE`.
  * Unescapes HTML entities (e.g., `&amp;` -> `&`, `&quot;` -> `"`).
  * Robust error handling for `Timeout`, `ConnectionError`, and HTTP status errors.

## 🧪 Automated Demo Execution

Run the built-in demo to test all 3 automations with a single command:
```bash
python main.py --task 4
```

This will automatically:
1. Create sample mixed files in `demo_data/raw_photos/` and move only JPEG files to `demo_data/organized_jpgs/`.
2. Generate `demo_data/company_directory.txt` and extract cleaned emails to `demo_data/unique_emails_output.txt`.
3. Fetch `https://en.wikipedia.org/wiki/Python_(programming_language)` and save its title and metadata to `demo_data/page_title_output.txt`.

## 📚 Key Concepts Used

- **`os`**: Path joining (`os.path.join`), directory creation (`os.makedirs`), file and directory inspection (`os.listdir`, `os.path.isfile`, `os.path.splitext`).
- **`shutil`**: Moving files across directories (`shutil.move`).
- **`re`**: Pattern matching with regular expressions for email validation and HTML `<title>` tag extraction.
- **`requests`**: Sending HTTP GET requests, custom request headers, timeouts, status code validation (`raise_for_status()`).
- **`file handling`**: Safe read and write operations with UTF-8 encoding (`open()`, `with` context manager).
- **`argparse`**: Command-line flag parsing for flexible script execution in both interactive and automated environments.
